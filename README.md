#Electric Vehicles Market Performance Dashboard
##Project Overview
This project analyzes electric vehicle market performance using Tableau.
##Objective
To visualize electric vehicle sales and market trends using interactive charts and dashboards.
##Tools used
-Tableau Public
-Data Visualization
-Data Analysis
##Dashboard Visualizations
1. Battery type pie chart
   Shows the distribution of different battery types, including LFP, NCA, NMC, Sodium-Ion, and Solid-State.
2. Market region heatmap
   Displays market performance across different regions and model years.
3. Drivetrain donut chart
   Shows the percentage distribution of AWD, FWD, and RWD drivetrain types.
4. Customer rating horizontal bar chart
   Compare customer rating across different vehicle categories.
5. Sales by model year line chart
   Shows sales trends across different model years.
6. Sales by category bar chart
   Compares sells across different vehicle category.
