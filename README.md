Electric Vehicles Market Performance Dashboard

Project Overview

This project analyzes electric vehicle market performance using Tableau.

Objective

To visualize electric vehicle sales and market trends using interactive charts and dashboards.

Tools Used

- Tableau Public
- Data Visualization
- Data Analysis

Dashboard Visualizations

1. Battery Type Pie Chart: Shows the distribution of different battery types.
2. Market Region Heatmap: Displays market performance across regions and model years.
3. Drivetrain Donut Chart: Shows the distribution of AWD, FWD, and RWD drivetrain types.
4. Customer Rating Horizontal Bar Chart: Compares customer ratings across vehicle categories.
5. Sales by Model Year Line Chart: Shows sales trends across different model years.
6. Sales by Category Bar Chart: Compares sales across different vehicle categories.
